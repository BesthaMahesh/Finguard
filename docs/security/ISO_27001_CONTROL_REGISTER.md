# FinGuard ISO/IEC 27001:2022 Control Register

**Platform:** FinGuard — Autonomous Financial Risk Intelligence Platform  
**Standard:** ISO/IEC 27001:2022 Information Security Management Systems (Annex A)  
**Document Classification:** Internal Technical Governance  
**Last Updated:** October 2026  
**Status:** In Progress / Partially Implemented (Application Technical Controls Only)  

> [!IMPORTANT]
> This control register maps technical controls implemented within the FinGuard application repository to ISO/IEC 27001:2022 Annex A controls. Implementation of technical software controls does **not** constitute ISO 27001 certification. Full certification requires an independently audited Information Security Management System (ISMS), formal organizational policies, employee awareness programs, operational risk treatment plans, and continuous surveillance audits.
